# See the Algorithm

Algorithms you can watch, each in one small JavaScript file with a live demo.
From the MahaDev YouTube channel's *See the Algorithm* Shorts.

| # | Episode | Demo | Code |
|---|---|---|---|
| 1 | Sorting race: Merge vs Quick vs Shell vs Heap | [live](https://ankit-alpha-q.github.io/see-the-algorithm/sort-race/) | [sort-race.js](./sort-race/sort-race.js) |

Every algorithm is a generator that `yield`s once per comparison, so each lane gets
the same number of comparisons per frame: a fair race.
