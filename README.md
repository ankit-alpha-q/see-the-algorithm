# See the Algorithm

Algorithms you can watch, each in one small JavaScript file with a live demo.
From the MahaDev YouTube channel's *See the Algorithm* Shorts.

| # | Episode | Demo | Code |
|---|---|---|---|
| 1 | Sorting race: Merge vs Quick vs Shell vs Heap | [live](https://ankit-alpha-q.github.io/see-the-algorithm/sort-race/) | [sort-race.js](./sort-race/sort-race.js) |
| 2 | BFS vs DFS vs A* on the same maze | [live](https://ankit-alpha-q.github.io/see-the-algorithm/maze-solve/) | [maze-solve.js](./maze-solve/maze-solve.js) |
| 3 | Why O(n²) hurts, on 300 bars | [live](https://ankit-alpha-q.github.io/see-the-algorithm/bubble-pain/) | [bubble-pain.js](./bubble-pain/bubble-pain.js) |
| 4 | Guess my number from 1 to 1000 | [live](https://ankit-alpha-q.github.io/see-the-algorithm/binary-search/) | [binary-search.js](./binary-search/binary-search.js) |
| 5 | Recursive backtracker: dig until stuck, back up, dig again | [live](https://ankit-alpha-q.github.io/see-the-algorithm/maze-gen/) | [maze-gen.js](./maze-gen/maze-gen.js) |
| 6 | Same Quick sort: shuffled vs already sorted input | [live](https://ankit-alpha-q.github.io/see-the-algorithm/quick-worst/) | [quick-worst.js](./quick-worst/quick-worst.js) |
| 7 | Fewest steps vs cheapest path on hilly terrain | [live](https://ankit-alpha-q.github.io/see-the-algorithm/dijkstra/) | [dijkstra.js](./dijkstra/dijkstra.js) |
| 8 | Two rules, endless patterns | [live](https://ankit-alpha-q.github.io/see-the-algorithm/game-of-life/) | [game-of-life.js](./game-of-life/game-of-life.js) |

Every algorithm is a generator that `yield`s once per comparison, so each lane gets
the same number of comparisons per frame: a fair race.
